# FingerDrill 指法特訓

鋼琴技巧練習工具:**考級音階/琶音抽考** + (第二階段)**哈農練習**。給考 ABRSM / Trinity 的學生,以及上課要點考的老師。
介面繁體中文、黑金設計系統(與 ScrollScore / HarmonyMap / HarmonyHands 同一系列),手機直式優先(iPhone 放在譜架上看)。

線上版(GitHub Pages,main 根目錄):<https://stevenmusic.github.io/FingerDrill/>

## 目前進度

- [x] **第一階段:音階抽考**(等你測試)
- [ ] 第二階段:哈農第一部分(1–20 首)程式化生成、12 調移調、速度階梯、節奏變化、最高速度紀錄
- [ ] 第三階段:每日練習紀錄與連續天數、Service Worker 離線、上架 App Store

## 第一階段功能

1. 選考試系統(ABRSM / Trinity)與級數 → 「本級要求」列出該級所有音階、琶音、半音階、反向音階、屬七/減七
2. **隨機抽考**:模擬考官點題,例如「E♭ 大調音階 · 雙手同時 · 兩個八度 · 圓滑奏」(Trinity 會加上指定力度 f / p)。不會連續抽到同一題,標成「待加強」的題目抽中機率加倍
3. **篩選範圍**:大調 / 小調、題型(音階、反向音階、琶音、半音階、屬七/減七)、排除已熟練的項目;小調形式(和聲 / 旋律 / 自然)照考生自選設定
4. **五線譜 + 指法**(OSMD):每個音都標指法(右手在上、左手在下),照標準記譜規則寫(符桿、臨時記號、休止符、連桿);
   音域高低時自動換譜號,超過 3 條加線就用 8va / 8vb;三連音只在第一組標「3」;可切換只看右手 / 左手 / 雙手
5. **播放示範**:ScrollScore 的取樣鋼琴(Salamander Grand,16 層力度),不用合成音;預備拍一小節,播放時游標跟著走;分手的題目「雙手」模式是右手彈完再彈左手
6. **節拍器**:預設該級的考試速度;− / + 點一下 ±1,按住連續增減(越按越快),也可以拖滑桿;可調慢(記住「考試速度的幾 %」,換題目時沿用);節拍器聲是真的鼓棒敲鼓框取樣
7. **熟練 / 待加強**標記存在 localStorage(同樣的要求跨級數、跨系統共用一筆)

## 檔案結構(沒有 build step,直接部署)

```
index.html              頁面
css/app.css             樣式(設計代幣照抄 HarmonyHands)
js/app.js               主程式(UI、OSMD、播放、節拍器)
js/theory.js            樂理:音名拼法、音階/琶音/半音階音高序列
js/fingering.js         指法:查表 + 屬七/減七/半音階規則
js/exercise.js          題目 → 兩手的音符與指法、考官點題文字
js/musicxml.js          練習 → MusicXML、播放時間表
js/syllabus.js          大綱 → 題目清單、篩選、隨機抽考
js/audio.js             取樣鋼琴與母帶鏈路(照 HarmonyHands / ScrollScore)、節拍器
js/store.js             localStorage
data/syllabus.json      考試要求(每級 verified: false,待核對)
data/fingerings.json    標準指法表
vendor/                 OpenSheetMusicDisplay 2.0.0(BSD-3-Clause)
tools/test/             自動驗證
tools/build/checklist.mjs  產生下面的核對清單
```

鋼琴與節拍器取樣直接從 `raw.githubusercontent.com/stevenmusic/ScrollScore/main/` 讀,下載後存在裝置的 Cache Storage。

## 驗證

```
node tools/test/verify.mjs          # 不需要瀏覽器
cd tools/test && npm i && node smoke.mjs   # 瀏覽器整合測試(Playwright)
cd tools/test && node notation.mjs         # 每一題實際畫譜比對
cd tools/test && node shot.mjs abrsm:3:maj:Eb   # 截圖某一題(手機直式/橫向/桌機)
```

`verify.mjs` 檢查:

- `syllabus.json` 結構(欄位、型別、鍵名、id 不重複、每級都有 `verified`、速度)
- `fingerings.json` 結構(長度、只有 1–5、第一個八度與循環一致、12 個調都有)
- 大綱裡每一題(三種小調形式都跑)+ **所有調 × 所有題型 × 1–4 個八度 × 同向/反向**:
  音高正確(與音程表比對)、拼法與音高一致、音階字母連續、起訖音、每個音都有指法、拇指不在黑鍵(全黑鍵的 F♯ 大三、E♭ 小三和弦除外)、
  上行手指銜接可彈(右手拇指只從 2/3/4 下面穿、左手只從拇指上面跨)、音階手指連續、5 指只在最高/最低音、反向從同一個音開始
- MusicXML:每小節每個譜表剛好 4 拍、音數 = 指法數、連桿成對
- **記譜規則**(另外寫一份檢查程式重新讀 MusicXML,不沿用產生器):
  符桿方向(一組連桿看離中線最遠的音;中線以上朝下)、臨時記號(同一小節同一音高有效到小節線,換譜號與 8va 不影響,照 Gould《Behind Bars》)、
  休止符從拍點起、二分休止符只在第 1/3 拍、不用附點休止符、全音符只在第 1 拍、二分音符只在第 1/3 拍、連桿不跨拍、三連音 3 個一組、
  加線不超過 3 條(超過就換譜號或 8va / 8vb)、全部音在鋼琴音域 A0–C8 內

`notation.mjs`:大綱裡每一題(三種小調形式,共 492 題)實際用 OSMD 畫出來,比對 OSMD 畫的臨時記號、指法數字、8va 標示與我們寫的是否一致。

`smoke.mjs`:手機與桌機各跑 ABRSM / Trinity 1–8 級抽題、樂譜真的畫出每一個指法數字、示範播放、節拍器、熟練標記重新整理後還在、排除熟練有作用、沒有橫向捲動、沒有 console 錯誤。

> 自動驗證只能確認「指法可彈、不違反規則」,不能確認是不是書上的那一種標準指法——下面的指法表請一併看過。

## ⚠️ 需要你逐級核對的清單

雲端環境連不到 abrsm.org / trinitycollege.com,`data/syllabus.json` 的內容是**憑記憶整理的草稿**,每一級都是 `"verified": false`,
App 裡也會顯示「大綱未核對」。請對照官方大綱逐項核對(調、分手/雙手、八度數、圓滑/斷奏、小調形式、速度),
改好的級數把 `verified` 改成 `true`(那一級的「未核對」標示就會消失)。

**目前還沒支援、如果大綱有要求請告訴我**:相隔三度/六度的音階、琶音轉位、半音階相隔小三度/大三度、
音階以外的技巧練習(Trinity 的 exercises)、Initial 級。
